# External datasets and services

The repository includes author-created synthetic scenarios and author-supplied historical
binary verdicts. It does not redistribute LongMemEval or LoCoMo source datasets.

- LongMemEval: https://github.com/xiaowu0162/LongMemEval
- LoCoMo: https://github.com/snap-research/locomo

Download external datasets from their authors and follow their current licensing,
attribution and use conditions. The MIT license in this repository applies to this
release's code and author-created materials; it does not relicense external datasets
or external model/API services.

The optional OpenRouter integration requires the user's own account and API key.
